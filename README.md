# -EcoHelp-Telegram-Bot

## Описание проекта

**EcoHelp** — это Telegram-бот, который помогает пользователям правильно сортировать отходы и находить ближайшие пункты переработки.  
Бот предоставляет актуальную информацию о переработке, интегрируется с геолокационными сервисами и способствует формированию экологически ответственного поведения.

---

## Установка

### Необходимые библиотеки

- Python 3.7 и выше  
- aiogram  
- requests  
- python-dotenv  

Установите зависимости командой:
```bash
pip install aiogram requests python-dotenv

Настройка
Создайте файл .env в корне проекта со следующей переменной:
TELEGRAM_BOT_TOKEN=ваш_токен_бота

Создайте основной скрипт bot.py с кодом бота.
Запуск бота
Локальный запуск
В терминале, находясь в папке проекта, выполните:

bash
Копировать код
python bot.py

Что увидит разработчик
В консоли появится сообщение:
Бот запущен...

Проверка работоспособности
В Telegram найдите вашего бота и отправьте команду /start.
Бот должен ответить приветственным сообщением.
Отправьте /help для просмотра списка команд.

Список команд бота

/start	Запуск бота и приветствие
/help	Справка по доступным командам
/sort	Информация о правильной сортировке отходов
/recycle	Поиск ближайших пунктов переработки по локации
/stats	Статистика использования бота
